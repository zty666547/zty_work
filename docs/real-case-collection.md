# 真实故障案例收集规范

最终实验只接收与现有三个故障族相关、能够确认根因的脱敏案例。公开帖子中只有报错但没有确认原因的记录，可作为待诊断案例，但不得计入准确率。

## 每条案例需要的信息

```text
案例编号：
故障族：Python导入 / PyTorch GPU与CUDA / 服务连接
原始报错或现象：
操作系统与关键版本：
最终确认的根因：
确认根因的检查过程：
哪些问题普通用户可以直接回答：
哪些问题需要运行命令或可能回答“不清楚”：
来源链接或脱敏截图说明：
是否允许计入准确率：是 / 否 / 待确认
```

## 纳入准确率的条件

- 根因由修复结果、维护者回复或可复现检查确认；
- 不包含账号、密钥、真实姓名和个人目录等敏感信息；
- 案例没有参与先验概率、可回答率和停止阈值的调整；
- 同一故障的重复转述只保留一条。

## 数据划分

- 开发集：只用于调整概率、可回答率和阈值；
- 测试集：参数冻结后运行，不能根据结果反向修改；
- 未确认集：用于展示系统如何继续询问，不计算准确率。
