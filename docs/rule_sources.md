# 培养规则来源清单

## 使用原则

- A 级：学校或学院正式培养方案，可作为专业与年级范围内的直接证据。
- B 级：北洋维基对官方规章或通知的转载、整理；保留原始链接与时间范围，关键结论继续寻找原文复核。
- 学期通知只适用于标注学期，不自动推广到其他学期。
- 不把智能体回答、论坛经验或群聊说法作为知识库事实。
