# 首批证据来源

| 来源 | 支持内容 |
|---|---|
| [Python内置异常](https://docs.python.org/3/library/exceptions.html) | ImportError与ModuleNotFoundError定义 |
| [Python环境变量](https://docs.python.org/3/library/os.html#os.environ) | 当前进程环境变量的读取语义 |
| [pip用户指南](https://pip.pypa.io/en/stable/user_guide/) | 使用指定解释器运行pip |
| [pip依赖解析](https://pip.pypa.io/en/stable/topics/dependency-resolution/) | 版本冲突、回溯与约束 |
| [PyTorch本地安装](https://pytorch.org/get-started/locally/) | 按操作系统和计算平台选择构建 |
| [PyTorch CUDA可用性](https://docs.pytorch.org/docs/stable/generated/torch.cuda.is_available.html) | CUDA运行时可用性检查 |
| [PyTorch MPS](https://docs.pytorch.org/docs/stable/notes/mps.html) | macOS上的MPS后端 |
| [Neo4j Python连接手册](https://neo4j.com/docs/python-manual/current/connect/) | URI、认证与`verify_connectivity()` |

`data/raw/debugpath_knowledge.json`记录了原因、检查、修复与这些来源之间的显式关系。当前版本没有把论坛回答当成事实来源。
